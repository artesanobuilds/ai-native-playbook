# Documents, research and interactive explainers

A recurring pattern in the archive is asking an agent to turn source material into something usable: a Markdown knowledge note, an interactive HTML explanation, a concise PDF, a visual status document or a spreadsheet.

## Research → knowledge library

Capture the source and date, extract the central ideas, separate quotations from interpretation, and save a readable Markdown note. When exploration benefits from interaction, build an accompanying HTML explanation with the same underlying content. Local prompts explicitly request Markdown alongside interactive visual summaries and ask for a proposed taxonomy before reorganizing an existing library.

Keep claims traceable to sources. A video summary should say whether the agent read a transcript, viewed frames or only had a description. Do not imply it watched material it could not access.

## Planning → shareable document

Start with audience and decision. Draft structure, then render a PDF or office document and inspect every page. Verify tables, wrapping, links and missing assets. The local history includes requests for succinct but visual status documents and a plan PDF accompanying a video draft.

Use source files as the durable artifact: Markdown/HTML, structured data and generation scripts. A final PDF alone is harder to revise.

## Data → analysis

Identify the dataset, time window, definitions and exclusions before calculating. Preserve raw data privately, use a repeatable transformation, and label provisional metrics. Inspect generated charts and spreadsheet formulas. Work-related source data remains in its authorized environment; only the general procedure belongs in this repo.

## Delivery

BB’s PDF and Office Preview plugins support in-thread inspection; Files Downloads provides saved-byte delivery. A preview and a download are separate capabilities. Check the actual browser-facing URL and expected bytes for files intended to be shared remotely.

Drafting a message or producing an attachment does not authorize sending it. Obtain the intended recipients and explicit send scope before external delivery.
