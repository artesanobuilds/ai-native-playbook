# Templates

- [Task brief](task-brief.md): define a concrete outcome.
- [Handoff](handoff.md): resume with a fresh agent.
- [Agent contract](agent-contract.md): scope a specialist before connecting accounts.
- [Setup report](setup-report.md): verify the rebuilt workstation.
- [ADR](adr.md): record a consequential decision.

Copy templates into your own private workspace and fill them in. Do not commit personal run reports or account details back to this public repo.
